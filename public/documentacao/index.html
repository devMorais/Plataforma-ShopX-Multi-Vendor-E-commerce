Manual do ShopX

Guia completo, de ponta a ponta, para operar a sua plataforma de marketplace multi-vendedor: administração, lojas parceiras e experiência de compra.

O que é o ShopX

O ShopX é uma plataforma de e-commerce multi-vendedor (marketplace). Vários lojistas podem vender no mesmo site, e o administrador controla tudo, cobrando uma comissão sobre cada venda — como funciona a Amazon, o Mercado Livre ou a Shopee.

🛍️

Loja online

Catálogo de produtos, carrinho, cupons, checkout e pagamento.

🏪

Multi-vendedor

Cada vendedor tem sua loja, seus produtos e seus pedidos.

💳

Pagamentos

PayPal, Stripe e Razorpay integrados e prontos para uso.

📊

Painel completo

Controle de produtos, pedidos, comissões, saques e aparência.

ℹ️
Tecnologia

Feito em Laravel 12 (PHP) com banco de dados MariaDB/MySQL. Você não precisa entender de programação para operar o sistema — este manual cobre o uso pelo navegador.

As 3 áreas do sistema

O ShopX tem três "portas de entrada" diferentes, cada uma para um tipo de usuário:

ÁreaQuem usaEndereço de acesso
AdminVocê, dono da plataforma/admin/login
VendedorLojistas parceiros/login → painel /vendor/dashboard
ClienteQuem compra/ (a loja) e /login

Admin Dashboard

É a tela inicial do painel. Mostra o resumo de saúde do negócio.

No Dashboard você acompanha de relance:

  • Faturamento e total de vendas no período;
  • Quantidade de pedidos (e seus status);
  • Número de produtos, vendedores e clientes cadastrados;
  • Gráficos de evolução de vendas e pedidos recentes.
💡

Use o Dashboard como ponto de partida diário: se um número parecer estranho (ex.: muitos pedidos "pendentes"), clique para investigar na seção correspondente.

Admin Categorias, Marcas e Tags

São as "gavetas" que organizam o catálogo. Configure-as antes de cadastrar produtos.

Categorias

Menu Categorias. As categorias podem ter subcategorias (estrutura em árvore: Ex.: Eletrônicos → Celulares → Smartphones).

  1. Clique em "Nova categoria" e preencha o nome.
  2. Defina a categoria-pai (opcional) para criar uma subcategoria.
  3. Envie uma imagem/ícone e marque se ela é destaque (aparece na home).
  4. Salve. Você pode arrastar para reordenar a posição das categorias.

Marcas

Menu Marcas. Cadastre fabricantes/marcas (Nike, Samsung…) com nome e logotipo. Cada produto é vinculado a uma marca.

Tags

Menu Tags. São etiquetas livres (ex.: "promoção", "novidade", "verão") usadas para agrupar e filtrar produtos de forma flexível.

ℹ️

Ordem recomendada de configuração: 1) Categorias → 2) Marcas → 3) Tags → 4) Produtos.

Admin Produtos

Menu Produtos. Aqui o administrador cadastra e gerencia produtos (os vendedores também cadastram os seus — veja a área Vendedor).

Tipos de produto

TipoO que éEntrega
FísicoMercadoria real (roupa, eletrônico…)Frete / envio
DigitalArquivo (e-book, curso, licença…)Download após a compra

Como cadastrar um produto

  1. Clique em "Adicionar produto" e escolha o tipo (Físico ou Digital).
  2. Informações básicas: nome, marca, categoria(s), tags, descrição curta e descrição completa.
  3. Preço: preço normal e, se quiser, um preço promocional com data de início e fim.
  4. Estoque: ative o controle de estoque e informe a quantidade (SKU para identificar).
  5. Imagens: envie as fotos (a primeira é a principal; arraste para reordenar).
  6. Atributos e variações (opcional): veja abaixo.
  7. Status: ativo para publicar. Salve.

Atributos e variações

Use quando o produto tem versões. Exemplo: uma camiseta com cores e tamanhos.

  1. Crie os atributos do produto (ex.: "Cor" com valores Azul/Preto; "Tamanho" com P/M/G).
  2. Gere as variações — o sistema combina os valores (Azul-P, Azul-M, Preto-G…).
  3. Defina preço e estoque por variação, se forem diferentes.

Produto digital

Ao escolher o tipo Digital, você envia o(s) arquivo(s) que o cliente vai baixar. Após a compra aprovada, o cliente acessa o download em Minha conta → Produtos comprados.

⚠️

Produtos só aparecem na loja quando estão com status ativo e (no caso de vendedores) aprovados pelo administrador.

Admin Pedidos

Menu Pedidos. Lista todas as compras feitas na plataforma.

  1. Clique num pedido para ver os detalhes: itens, valores, cliente, endereço, pagamento e comissão.
  2. Atualize o status conforme o pedido avança.

Status de um pedido

StatusSignificado
PendentePedido criado, aguardando processamento/pagamento.
Em processamentoPagamento confirmado, sendo preparado.
EnviadoDespachado para entrega.
EntregueRecebido pelo cliente.
CanceladoPedido cancelado.

Há também o status de pagamento (pago / não pago), atualizado automaticamente pelo gateway quando o cliente paga.

Admin Cupons

Menu Cupons. Crie códigos de desconto para campanhas.

  1. Novo cupom: defina o código (ex.: BEMVINDO10).
  2. Tipo de desconto: percentual (ex.: 10%) ou valor fixo (ex.: R$ 20).
  3. Regras: valor mínimo de compra, limite de usos e validade (datas).
  4. Salve. O cliente digita o código no carrinho.
💡

Cupons com validade e limite de uso evitam abusos e criam urgência ("só até domingo!").

Admin Regras de frete

Menu Regras de envio. Define quanto o cliente paga de frete.

  • Crie regras por região, valor do pedido ou método (normal/expresso).
  • Configure frete grátis acima de determinado valor para incentivar compras maiores.

No checkout, o cliente escolhe o método de envio disponível e o valor é somado ao total.

Admin Formas de pagamento

Menu Configurações de pagamento. O ShopX já vem com três gateways integrados:

🅿️

PayPal

Modo sandbox (teste) ou live (real). Client ID e Secret.

💠

Stripe

Cartões internacionais. Chaves publishable e secret.

🇮🇳

Razorpay

Gateway popular na Índia. Key ID e Secret.

  1. Abra a aba do gateway desejado (PayPal / Stripe / Razorpay).
  2. Cole as chaves da sua conta no gateway (geradas no painel do PayPal/Stripe/Razorpay).
  3. Escolha o modo: sandbox para testar, live para receber de verdade.
  4. Ative e salve. O gateway passa a aparecer no checkout.
⚠️

Comece sempre em sandbox e faça uma compra de teste antes de mudar para live. Nunca compartilhe suas chaves secretas.

Admin Vendedores e KYC

O ShopX é um marketplace — outras pessoas podem vender. Antes de venderem, os vendedores passam por uma verificação de identidade (KYC).

Aprovar/rejeitar um vendedor

  1. Menu Solicitações de KYC. Veja as abas Pendentes e Rejeitadas.
  2. Abra a solicitação e confira os dados e o documento enviado (você pode baixá-lo).
  3. Aprove (o vendedor é liberado para vender) ou rejeite (informando o motivo).
ℹ️

Enquanto o KYC não é aprovado, o vendedor pode acessar o painel, mas seus produtos não são publicados.

Admin Comissões e saques

É assim que a plataforma ganha dinheiro e que os vendedores recebem.

Comissão

Em Configurações → Comissão, defina o percentual que a plataforma retém de cada venda (ex.: 15%). A cada pedido pago, o sistema calcula automaticamente: a sua comissão e o valor líquido do vendedor.

Métodos de saque

Menu Métodos de saque: defina os meios pelos quais os vendedores podem solicitar o dinheiro (ex.: PIX, transferência bancária, PayPal).

Solicitações de saque

  1. O vendedor solicita um saque do saldo acumulado.
  2. Você revisa em Solicitações de saque.
  3. Faça o pagamento pelo método escolhido e marque a solicitação como paga/aprovada.

Admin Avaliações

Menu Avaliações. Lista as avaliações (estrelas + comentário) que os clientes deixaram nos produtos. Você pode excluir avaliações ofensivas ou falsas.

Admin Newsletter

Menu Inscritos. Mostra os e-mails de quem se cadastrou para receber novidades. Em Enviar newsletter, você dispara um comunicado para toda a lista.

ℹ️

O envio de e-mails depende da configuração de e-mail do servidor (SMTP). Para a demonstração, os e-mails ficam apenas registrados em log.

Admin Contato e mensagens

Em Mensagens de contato ficam as mensagens enviadas pelo formulário "Fale conosco" da loja. Em Configurações de contato você ajusta o texto, telefone, e-mail e endereço exibidos na página de contato.

Admin Páginas personalizadas

Menu Páginas personalizadas. Crie páginas de conteúdo como Sobre nós, Política de privacidade, Termos de uso e Trocas e devoluções.

  1. Nova página: defina título e conteúdo (editor de texto).
  2. Salve. A página fica acessível em /page/o-titulo-da-pagina e pode ser linkada no rodapé.

Admin Funções e permissões

Menus Funções e Usuários de função. Permitem criar perfis de acesso à administração (ex.: um funcionário que só vê pedidos, outro que gerencia produtos).

  1. Crie uma função (ex.: "Operador de pedidos").
  2. Marque as permissões que ela pode acessar.
  3. Associe usuários administradores a essa função.
💡

O Super Admin tem acesso a tudo. Crie funções limitadas para a sua equipe seguindo o princípio do "mínimo acesso necessário".

Admin Limpar dados ⚠️

Menu Limpar banco de dados. Apaga dados de demonstração para começar do zero.

🛑
Ação irreversível

Isto apaga produtos, pedidos e/ou clientes permanentemente. Faça um backup do banco antes (veja a seção "Backup"). Use somente quando for de fato limpar a demonstração para entrar em operação real.

Vendedor Tornar-se vendedor

Qualquer cliente pode virar vendedor e abrir uma loja dentro do marketplace.

  1. Crie uma conta / faça login como cliente em /login.
  2. Solicite virar vendedor e preencha a verificação KYC (/kyc-verification): dados pessoais e documento.
  3. Aguarde a aprovação do administrador.
  4. Aprovado! O painel do vendedor é liberado em /vendor/dashboard.

Vendedor Dashboard do vendedor

Resumo da loja: vendas, pedidos recebidos, saldo disponível para saque e produtos mais vendidos.

Vendedor Perfil da loja

Menu Perfil da loja. O vendedor configura a identidade da sua loja:

  • Nome da loja, logotipo e banner;
  • Descrição curta e completa;
  • Contato: telefone, e-mail e endereço.

Essa página é o que os clientes veem em /vendors/nome-da-loja.

Vendedor Cadastrar produtos

Menu Produtos do painel do vendedor. O processo é igual ao do admin (veja Produtos): tipo, preço, estoque, imagens, atributos e variações.

⚠️

Produtos cadastrados por vendedores entram como "pendente de aprovação". Só vão para a loja depois que o administrador aprovar.

Vendedor Gerenciar pedidos

Menu Pedidos. O vendedor vê apenas os pedidos dos seus produtos, e atualiza o status (em processamento → enviado → entregue) conforme prepara e despacha.

Vendedor Receber pagamentos (saques)

  1. Cadastre um método de saque (PIX, conta bancária…) em Métodos de saque.
  2. Solicite o saque do saldo disponível em Solicitações de saque.
  3. Acompanhe o status — o administrador processa e paga.
ℹ️

O saldo disponível já vem descontada a comissão da plataforma.

Cliente Navegar e buscar

A experiência de compra na loja, passo a passo.

  • Busca: a barra no topo procura por nome de produto.
  • Categorias: o menu "Categorias em Alta" e a navegação levam às listagens.
  • Filtros (em /products): por categoria, marca, faixa de preço e tags.
  • Vendedores: em /vendors dá para navegar pelas lojas.
  • Ofertas: a página /flash-sales mostra as promoções relâmpago.

Cliente Página do produto

Ao clicar num produto, o cliente vê: galeria de fotos, preço (e preço promocional, se houver), descrição, avaliações, vendedor e — quando existem — as variações (cor, tamanho).

  1. Escolhe a variação e a quantidade.
  2. Adiciona ao carrinho ou à lista de desejos (wishlist).

Cliente Carrinho e cupom

  1. Abre o carrinho (ícone no topo).
  2. Ajusta as quantidades ou remove itens.
  3. Aplica um cupom de desconto, se tiver o código.
  4. Segue para o checkout.

Cliente Checkout

  1. Endereço de entrega: escolhe um endereço salvo ou cadastra um novo.
  2. Método de envio: seleciona o frete disponível (o valor entra no total).
  3. Dados de cobrança: confirma as informações de faturamento.
  4. Revisa o resumo (itens, frete, desconto, total) e avança para o pagamento.

Cliente Pagamento

O cliente escolhe um dos gateways ativos (PayPal, Stripe ou Razorpay), é levado ao ambiente seguro do gateway e conclui o pagamento.

  • Pagamento aprovado: o pedido é confirmado e o cliente volta à página de sucesso.
  • Pagamento cancelado: o pedido fica pendente e o cliente pode tentar de novo.
ℹ️

Em produtos digitais, assim que o pagamento é aprovado, o download é liberado em Minha conta → Produtos comprados.

Fluxo completo (exemplo)

Juntando tudo: do cadastro do produto até o vendedor receber o dinheiro.

  1. Admin prepara o catálogo: cria categorias, marcas e define a comissão (ex.: 15%).
  2. Vendedor se cadastra: abre conta, envia o KYC e configura a loja.
  3. Admin aprova o KYC do vendedor.
  4. Vendedor cadastra um produto (preço R$ 100, com fotos).
  5. Admin aprova o produto → ele aparece na loja.
  6. Cliente compra: adiciona ao carrinho, aplica cupom, faz checkout e paga.
  7. Sistema registra o pedido como pago e calcula: R$ 15 de comissão + R$ 85 para o vendedor.
  8. Vendedor envia o produto e marca como enviado/entregue.
  9. Vendedor solicita o saque dos R$ 85.
  10. Admin paga o saque e marca como concluído. ✅

Atualizar o site no ar

O site fica na Hostinger e o código no GitHub. Para publicar uma mudança feita no seu computador:

1. No seu computador

# envia suas mudanças para o GitHub
git add .
git commit -m "Descricao do que mudou"
git push origin main

2. No servidor (Hostinger, via SSH)

ssh -p 65002 u846585591@147.93.39.159
cd ~/domains/devmorais.com.br/public_html/shopx
git pull origin main
php artisan migrate --force
php artisan optimize:clear
php artisan config:cache && php artisan route:cache && php artisan view:cache
💡

Se mudou o visual (CSS/JS), rode npm run build no seu PC antes do git push para enviar os arquivos compilados.

Backup do banco de dados

Antes de qualquer ação arriscada (limpar dados, grandes mudanças), salve uma cópia do banco.

Opção A — pelo painel da Hostinger

hPanel → Bancos de Dados → phpMyAdmin → selecione o banco → aba Exportar → método rápido → Executar. Um arquivo .sql é baixado.

Opção B — pelo SSH

cd ~/domains/devmorais.com.br/public_html/shopx
MYSQL_PWD='SUA_SENHA' mysqldump -u u846585591_shopx_u u846585591_shopx_u > backup_$(date +%F).sql
ℹ️

Guarde os backups em local seguro (Google Drive, etc.). Faça backups com regularidade quando o site estiver em operação real.

Dúvidas frequentes

As imagens não aparecem / mudei algo e não atualizou

Quase sempre é o cache do navegador. Faça um hard refresh com Ctrl + Shift + R ou abra em aba anônima.

Um produto não aparece na loja

Verifique se ele está com status ativo e, se for de um vendedor, se está aprovado. Confira também se há estoque.

O pagamento não funciona

Confirme em Configurações de pagamento se o gateway está ativo e com as chaves corretas. Teste primeiro em modo sandbox.

O vendedor não consegue vender

O KYC dele provavelmente ainda não foi aprovado. Verifique em Solicitações de KYC.

Esqueci a senha do admin

Use "Esqueci a senha" na tela de login (precisa de e-mail configurado) ou peça a quem administra o servidor para redefinir via comando.

Como deixar em Português e Real (R$)?

A interface já está em PT-BR. Para a moeda, vá em Configurações → Gerais e troque a moeda para BRL e o símbolo para R$.
